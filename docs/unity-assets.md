# Unity Asset Store: what the account can download

Scanned 2026-11-18 from the signed-in Unity account's Asset Store library (Package Manager's *My Assets*, read through the editor's own Asset Store API). The library holds **27 packages, 69.3 GB to download in all**, every one by the publisher **Hivemind**, all added to the account on 2026-11-18 (a bundle).

None of them are already in the project: the packs in `Assets/Carrier/Kit` (Mega City, Starship, Spaceship Kit, Orbital Base, Space Colony 2086 and the rest) come from elsewhere and are not in this library.

## Before importing any of them

- **Licence:** Asset Store content may not be published. Anything imported goes under `Assets/Carrier/Kit/` (git-ignored), never into the public repo, the same as the existing Kit.
- **Render pipeline:** every pack was made in HDRP; each includes a URP package to import instead (this project is URP). The gun VFX also covers Built-in.
- **Unity version:** uploaded from Unity 2021.3, 2022.3 or 6000.0. They import into 6000.6, but expect material upgrades and some shader warnings.
- **Size:** most are 1-5 GB, mostly 4K textures. Import only what's used, and check build size (the Windows zip is about 520 MB now).
- **Download:** Window > Package Manager > *My Assets* in the editor, signed in to the same account.

## The useful ones

- **Bunker Builder: Modular Bunker Building Kit** (high): Underground bunkers, sci-fi labs and military bases: base interiors and fortified surface sites.
- **Modular Sci Fi Outpost** (high): Sci-fi outpost with interiors, screens and alien rocks: surface bases, mining outposts, landing-pad surroundings.
- **Realistic Fire VFX** (high, now used): VFX Graph fire, embers and smoke, on burning wrecks and on settlements struck from orbit (`Tools/stage_firefx.py`, `CarrierBuilder.FireFx`). The Visual Effect Graph package is in the manifest for it. VFX Graph needs compute shaders, so the web game shows no fires when it falls back to WebGL 2.
- **Realistic Gun VFX** (high): Muzzle flashes, impacts, decals, tracers and an overheat effect: turret and point-defence fire, hull hits.
- **Modular Cave** (medium): Caves and ancient temples: the Ruins of the Ancients, asteroid interiors.
- **Modular Destroyed Buildings** (medium): Ruined, half-collapsed buildings (fantasy styling): bombed settlements, the Ruins of the Ancients.
- **Modular Dungeon: Temple Of Cthulhu** (low): Alien-temple dungeon: possibly a Vrask or ancient site, but strongly Cthulhu-themed.
- **Modular Haunted House** (low): Post-apocalyptic house kit: colony interiors at most.

The other 19 packages are medieval towns and castles, dungeons, haunted houses, a gladiator arena, a pirate island, furniture, stylized nature and blood effects: nothing a space game would use, apart perhaps from the nature packs' rocks for planet surfaces.
